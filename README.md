# File Online Manager

**Свой файловый менеджер в браузере.** Открывает папки на вашем компьютере или сервере, загружает и скачивает файлы, показывает превью — с одного устройства, без облака и подписок.

Поднимается одной командой, работает локально или в домашней сети. Вход по паролю, сессии в памяти, всё остальное — на диске у вас.

> **EN:** A self-hosted web file manager. Browse and mount local folders, upload/download files, preview media, plus built-in modules: notes, todos, bookmarks, password vault, favorites, trash, recent and a real-time chat hub over WebSocket. Node.js + Express, no database.

---

## Зачем это

Облачные диски требуют регистрации, платят за гигабайты и кладут ваши файлы на чужой сервер. Здесь — то же самое, но на вашей машине: открыли в браузере на телефоне, посмотрели папку на компьютере, скачали файл. Пока компьютер включён.

## Возможности

**Файлы**
- Просмотр папок в виде списка, навигация по дереву
- Виртуальные папки: подключаете любые пути под своими именами
- Загрузка файлов (drag-and-drop, до 2 ГБ по умолчанию)
- Скачивание, удаление, переименование
- Превью картинок, видео и документов
- Конвертация офисных форматов через LibreOffice

**Модули**
- **Заметки, задачи, закладки** — рабочий стол внутри менеджера
- **Хранилище паролей** — локально, в вашем файле, без синхронизации наружу
- **Избранное, корзина, недавние, теги**
- **Hub** — чат в реальном времени через WebSocket, с цветными аватарами по нику

**Безопасность**
- Вход по паролю, сессия живёт 24 часа
- Защита от перебора: лимит 5 попыток входа в минуту
- Случайный пароль при первом запуске, если `AUTH_PASS` не задан
- Журнал доступа в `storage/access.log`

## Стек

| Слой | Что используется |
|---|---|
| Бэкенд | Node.js, Express 4, multer, ws, mime-types |
| Документы | libreoffice-convert |
| Фронтенд | один файл `index.html`, без фреймворков |
| Хранилище | JSON-файлы в `storage/`, без БД |

## Быстрый старт

```bash
git clone https://github.com/Qatrol/fileonlinemanager.git
cd fileonlinemanager
npm install
cp .env.example .env      # Windows: copy .env.example .env
# задайте AUTH_PASS и BASE_ROOT
npm start
```

Откройте `http://localhost:47821`. В консоли сервер напечатает адреса в локальной сети — по ним можно зайти с телефона.

## Настройка

| Переменная | Обязательна | Описание |
|---|---|---|
| `AUTH_PASS` | нет | пароль входа. Если пусто — генерируется случайный и печатается один раз |
| `BASE_ROOT` | нет | корневая папка, по умолчанию `D:\Work` |
| `MOUNTS` | нет | виртуальные папки в формате `Имя:путь,Имя2:путь2` |
| `PORT` | нет | порт, по умолчанию `47821` |
| `MAX_UPLOAD_MB` | нет | лимит загрузки, по умолчанию `2048` |

## Структура

```
fileonlinemanager/
├─ server.js          # Express: авторизация, файловые операции, загрузка, сессии
├─ index.html         # весь интерфейс
├─ modules/
│  ├─ apps.js         # заметки, задачи, пароли, закладки
│  ├─ extras.js       # избранное, корзина, недавние, теги
│  └─ hub.js          # чат через WebSocket
├─ .env.example
└─ storage/           # создаётся автоматически, в git не попадает
```

## Важно про данные

`storage/` содержит ваши логи, переписку и, если пользуетесь модулем паролей, — **эти пароли в открытом виде**. Папка исключена из git. Не выкладывайте её никуда и делайте бэкап отдельно.

Сервер не стоит открывать напрямую в интернет: для доступа снаружи нужен reverse-proxy с HTTPS и, желательно, VPN.
